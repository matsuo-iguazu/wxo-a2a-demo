# 海外出張規程（サンプル）

> 本書はデモ用のサンプル規程です。実際の企業規程とは異なります。

---

## 第1条 目的

本規程は、従業員が業務上の目的で海外に出張する際の手続き、安全管理、費用精算に関する基準を定める。

---

## 第2条 渡航危険度レベルと出張可否

外務省の**感染症危険情報・海外安全情報**および社内安全管理部門の評価に基づき、渡航先の危険度を以下の4段階に分類する。

| 危険度レベル | 分類名 | 出張可否 | 承認要件 |
|---|---|---|---|
| **レベル1** | 注意喚起 | ✅ 原則許可 | 部門長承認 |
| **レベル2** | 危険情報（一部地域） | ✅ 条件付き許可 | 部門長 + 安全管理部門承認・危機管理保険加入必須 |
| **レベル3** | 渡航中止勧告 | ❌ **原則禁止** | 役員承認が得られた場合のみ例外対応可（危機管理保険・連絡体制整備が条件） |
| **レベル4** | 退避勧告 | ❌ **出張不可** | 例外なし・一切認めない |

> **重要**：レベル3・レベル4の地域への出張申請は受理されません。出張不可の地域が含まれる場合、申請書の提出前に必ず安全管理部門に相談してください。

### 危険度レベル3・レベル4に該当する主な地域（2024年時点・例示）

| 地域 | 危険度 | 備考 |
|---|---|---|
| アフガニスタン全域 | レベル4 | 退避勧告 |
| シリア全域 | レベル4 | 退避勧告 |
| ロシア全域 | レベル3 | 渡航中止勧告 |
| ウクライナ全域 | レベル4 | 退避勧告 |
| イラク（バグダード等） | レベル3 | 一部地域レベル4 |
| イエメン全域 | レベル4 | 退避勧告 |
| リビア全域 | レベル3 | 大部分がレベル4 |
| マリ全域 | レベル3 | 退避勧告 |
| ソマリア全域 | レベル4 | 退避勧告 |
| スーダン全域 | レベル4 | 退避勧告 |
| ハイチ（全土） | レベル3 | 渡航中止勧告 |
| ミャンマー全域 | レベル3 | 渡航中止勧告 |
| 北朝鮮全域 | レベル4 | 退避勧告 |
| パレスチナ（ガザ地区） | レベル4 | 退避勧告 |

> **免責事項**：上記リストはデモ用のサンプルです。実際の危険度レベルは外務省の公式情報（https://www.anzen.mofa.go.jp/）を参照してください。

## 第3条 申請手続き

### 申請タイミング

| 出張期間 | 申請提出期限 |
|---|---|
| 3日以内 | 出発5営業日前まで |
| 4日〜2週間 | 出発10営業日前まで |
| 2週間超 | 出発20営業日前まで |

### 申請書の記載事項（必須）

1. 出張者氏名・所属・社員番号
2. 出張目的（業務内容を具体的に記載）
3. 渡航先国・都市
4. 出発日・帰国日（日程）
5. 訪問先企業・機関名
6. 緊急連絡先（現地・国内各1件）
7. 宿泊先名称・住所・電話番号
8. 海外旅行保険加入確認（保険証券番号）
9. 渡航先の危険度レベル確認欄（申請者自己確認）

---

## 第4条 費用規程（日当・宿泊費上限）

### 渡航先別日当（1日あたり）

| 渡航先地域 | 日当 |
|---|---|
| 北米・西欧・オセアニア・シンガポール | 7,000円 |
| 東欧・中東・南米・アジア（主要都市） | 5,000円 |
| 東南アジア・南アジア・アフリカ | 4,000円 |
| 中国・韓国・台湾・香港 | 4,500円 |

### 宿泊費上限（1泊あたり、朝食込み）

| 渡航先地域 | 上限額 |
|---|---|
| 北米・西欧 | 35,000円 |
| シンガポール・オーストラリア | 30,000円 |
| 中東・東欧・南米 | 25,000円 |
| 東南アジア・東アジア | 20,000円 |
| 南アジア・アフリカ | 15,000円 |

> 上限を超える場合は、事前に部門長の承認が必要。

### 航空券

- **エコノミークラス**が原則。フライト時間が**8時間以上**の場合はビジネスクラスを申請可。
- 旅行代理店経由での購入を原則とする（個人手配は事後精算で上限あり）。

---

## 第5条 海外旅行保険

すべての海外出張に対し、以下の補償内容を含む**危機管理保険**への加入が必須。

| 補償内容 | 最低補償額 |
|---|---|
| 治療・救援費用 | 無制限 |
| 賠償責任 | 1億円 |
| 携行品損害 | 50万円 |
| 緊急搬送 | 無制限 |

- 保険証券は出発前に総務部へ写しを提出すること。
- 危険度レベル2以上の地域は、追加の**危機管理特約**の加入が必要。

---

## 第6条 健康管理・ワクチン接種

| 渡航先 | 推奨ワクチン・措置 |
|---|---|
| 東南アジア・南アジア・アフリカ | A型肝炎・腸チフス・マラリア予防薬 |
| アフリカ（サハラ以南） | 黄熱病（入国要件の場合は必須）・マラリア予防薬 |
| 中南米 | 黄熱病・A型肝炎 |
| 中東 | A型肝炎・腸チフス |
| 全地域共通 | 渡航前の健康診断（1年以内）・常備薬持参 |

---

## 第7条 緊急時連絡体制

出張中に緊急事態が発生した場合は、以下の手順に従う。

1. **身の安全の確保**を最優先
2. 安全管理部門の24時間緊急ホットライン（社内イントラ参照）へ連絡
3. 直属の部門長へ報告
4. 在外公館（日本大使館・領事館）への届け出
